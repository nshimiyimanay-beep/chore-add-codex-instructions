02 / PUBLISHING

Controlled publishing workflow

1Sign in to Pages CMS with GitHub
2Choose this repository and the website development branch
3Update text, images or portfolio entries
4Save to GitHub and review the updated preview
5Approve releases before merging into production

Pages CMS requires one-time GitHub authorization. This dashboard is a public read-only management entry: no password is stored here, and only accounts permitted by GitHub can save edits. The production website is not automatically launched by opening this page.

03 / ACCESS

One-time connection

Open Pages CMS, sign in with the GitHub account that owns the ISO MEGA repository, authorize the GitHub App for this repository only, and select the feat/admin-cms-v1 branch while reviewing the CMS. Once the branch is merged into the approved preview branch, select that branch instead.

Already connected? Open the content editor and choose the relevant content section from its sidebar. You can return to this overview at any time.
